# ZY驿站

纯静态、零依赖，直接部署到 GitHub Pages。全部为原生 HTML/CSS/JS 手写，零框架、零构建依赖。

## 功能一览
- 🖼 **全屏 Banner**：Ken Burns 缓慢缩放背景 + 波浪分隔 + 打字机副标题 + 圆形按钮
- 👧 **人物立绘**：右下角动漫风角色（本地 SVG，可换成你自己的图）
- 📚 **文章卡片**：封面图 / 分类角标 / 摘要 / 作者头像 / 日期 / 阅读时长 / 字数 / 标签
- 🏷 **标签墙 + 分类墙**：自动统计数量，按热度排序
- 🗂 **归档时间轴**：按年份分组，带发光节点
- 🗄 **侧栏抽屉 + 桌面固定侧栏**：首页/标签/分类/归档/关于/留言板/友情链接/GitHub
- 🔍 **搜索弹窗**：全站文章实时检索（标题/摘要/标签/分类）
- ❄️ **飘雪特效**：canvas 轻量实现，可被系统「减少动态效果」自动关闭
- 🖱 **指针流光**：鼠标/手指划过留下光带（保留原有特效）
- 🌗 **暗/亮主题切换**（localStorage 记忆）
- 👣 **页脚统计**：运行时间实时滴答 / 访问量 / 访客数
- 💬 **留言板**：纯前端 localStorage（无后端）
- 🔗 **上一篇 / 下一篇** 导航、回到顶部、阅读进度条
- 🗺 自动生成 `sitemap.xml`

## 修掉的真 bug：正文里的字面量 `<br>`
根因：段落拼接写成 `inline(para.join('<br>'))` —— 先插 `<br>` 再转义，于是每一处换行都变成了可见的 `<br>` 文字。
修复：改为 `para.map(inline).join('<br>')`（先转义每行，再插真换行）；另外把作者手写的 `<br>` / `</br>` 统一转成空行。
复测：全站 14 页「字面量 `<br>`」= **0**，真换行 377 处（正常）。

## 清缓存
每个页面 `<head>` 都写入：
```html
<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">
<meta http-equiv="Pragma" content="no-cache">
<meta http-equiv="Expires" content="0">
```
配合"单文件自包含"（CSS/JS/数据/图全内联），刷新一次即是最新版。本地预览可用 `?v=时间戳` 强制绕过缓存。

## 深色模式对比度修复（本轮，你截图里的问题）
**现象**：深色（墨夜）下正文/引用块/代码几乎看不见。根因：水墨配色（`#3d3a34` / `#2c2925` / `#9d2933` / `#46603f` / `#7a5a33`）只写了浅色一套，深色模式没有对应值；引用块还留着浅色底 `rgba(238,242,244,.6)`，于是浅底浅字。

## 修掉一个真 bug：SVG data URI 里的括号没转义
**症状**：文章页顶图**空白**、卡片封面只有底纹、Banner 看不到云海/月亮。
**根因**：封面/横幅 SVG 内部有 `url(#渐变)`，而 `encodeURIComponent` **不会转义 ( ) '**。把这样的 data URI 放进 CSS 的 `url(...)` 时，**第一个 `)` 就把地址截断**了 → 图片根本没加载。
**修复**：新增 `cssUri()`（在 `board_cover.js` 内），统一把 `(` `)` `'` 转义成 `%28 %29 %27`；Banner、favicon、卡片封面、文章顶图**全部改用它**。
**核查**：首页 14 个 SVG data URI **全部合法可渲染**；文章顶图 0 个裸括号；Banner 也恢复显示（远山 + 淡月）。
