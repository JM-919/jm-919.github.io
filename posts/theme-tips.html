让博客梦幻 10 倍的 CSS 技巧

2026-01-03 · 4 分钟

1. 变量驱动的梦幻色板

:root{
  --bg:#0b0716; --p1:#a78bfa; --p2:#f0abfc; --p3:#67e8f9;
  --fg:#f3ecff; --muted:#b9a8d8;
}

2. 极光光球背景

.aurora::before{
  width:60vmax; height:60vmax; border-radius:50%;
  background:radial-gradient(circle,rgba(167,139,250,.55),transparent 62%);
  filter:blur(70px);
  animation:dream-float 26s ease-in-out infinite alternate;
}

3. 卡片彩虹描边

.card::after{
  content:""; position:absolute; inset:0; padding:1px;
  background:linear-gradient(120deg,#f0abfc,#a78bfa,#67e8f9);
  -webkit-mask:linear-gradient(#000 0 0) content-box,linear-gradient(#000 0 0);
  -webkit-mask-composite:xor; mask-composite:exclude;
}

4. 渐变文字 + 光晕

em{
  background:linear-gradient(100deg,#f0abfc,#a78bfa 45%,#67e8f9);
  -webkit-background-clip:text; color:transparent;
  filter:drop-shadow(0 0 24px rgba(240,171,252,.55));
}

5. 指针流光拖尾（Canvas）

ctx.globalCompositeOperation = 'lighter';
addEventListener('pointermove', e => spawn(2, e.clientX, e.clientY));
// 生命值衰减 + 径向渐变光斑 = 柔和拖尾
