从零搭建一个漂亮的 GitHub Pages 博客

2026-01-01 · 5 分钟

1. 目录结构

.
├── index.html          # 首页（卡片 + 搜索）
├── archive.html        # 归档
├── about.html          # 关于
├── posts/              # 文章
└── assets/
    ├── css/style.css   # 全部样式（主题变量）
    └── js/main.js      # 主题切换 / 进度条 / 搜索

2. 开启 GitHub Pages

git init && git add . && git commit -m "init blog"
git branch -M main
git remote add origin https://github.com/JM-919/jm-919.github.io.git
git push -u origin main
仓库名必须是 JM-919.github.io，站点地址才是 https://jm-919.github.io。推送后到 Settings → Pages 选择 main 分支根目录。

3. 换成自己的信息

占位符含义
秋秋小窝站点名
记录代码、折腾与灵感的小站站点描述（SEO）
秋秋作者名

4. 写新文章

复制 posts/hello-world.html，改标题与正文，再到 index.html 的 #posts 里复制一张卡片即可。
