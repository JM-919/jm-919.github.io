从零搭建一个梦幻的 GitHub Pages 博客

2026-01-01 · 5 分钟

1. 目录结构

.
├── index.html          # 首页（卡片 + 搜索）
├── archive.html        # 归档
├── about.html          # 关于
├── posts/              # 文章
└── assets/
    ├── css/style.css   # 梦幻主题（变量 / 玻璃拟态 / 星空）
    └── js/
        ├── main.js     # 主题切换 / 进度条 / 搜索
        └── dream.js    # 全局指针流光拖尾

2. 开启 GitHub Pages

git init && git add . && git commit -m "init blog"
git branch -M main
git remote add origin https://github.com/JM-919/jm-919.github.io.git
git push -u origin main
仓库名必须是 JM-919.github.io，站点地址才是 https://jm-919.github.io。推送后到 Settings → Pages 选择 main 分支根目录。

3. 换成自己的信息

仓库里带了 personalize.sh，一条命令改全站站名 / 描述 / 作者 / 账号 / 邮箱：

bash personalize.sh "Felix" "梦幻流光 · 记录代码与折腾的小站" "Felix" "JM-919" "xyxf13@gmail.com"
参数含义
第 1 个站点名（标题栏 / 导航栏）
第 2 个站点描述（SEO）
第 3 个作者名（首页问候 / 页脚）
第 4 个GitHub 用户名（关于页链接）
第 5 个邮箱（可省略）

4. 写新文章

复制 posts/hello-world.html，改标题与正文，再到 index.html 的 #posts 里复制一张卡片即可。
